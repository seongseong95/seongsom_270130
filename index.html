HOW IT WORKS

① 캐릭터 만들기 → ② 축하 메시지 등록 → ③ 전체 축하 월에 실시간 반영 → ④ 관리자 정렬 → ⑤ PNG / 영상으로 저장

사전 참여는 모바일 청첩장 링크를 통해 진행하고, 예식 당일에는 관리자가 참여를 마감한 뒤 영상 파일을 최종 출력하는 것을 권장합니다.
